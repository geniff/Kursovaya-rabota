# Обоснование выбора технологического стека для фронтенда (PHP + Laravel)

**Разработчик:** Королева Дарья

## 1. Язык программирования PHP (версия 8.1+)
PHP — скриптовый язык общего назначения, наиболее широко используемый для веб-разработки. На сегодняшний день (PHP 8+) обладает современными возможностями и высокой производительностью.

**Причины выбора для проекта:**
- **Простота и скорость разработки.** PHP позволяет быстро создавать динамические веб-страницы, интегрироваться с HTML.
- **Огромное сообщество и экосистема.** Масса готовых решений, библиотек, фреймворков.
- **Отличная совместимость с веб-серверами** (Apache, Nginx) и базами данных.
- **Низкий порог входа.** При необходимости к проекту могут легко подключиться другие разработчики.
- **Поддержка современных парадигм** (ООП, типизация, анонимные функции, JIT-компиляция в PHP 8).

## 2. Фреймворк Laravel 10
Laravel — самый популярный PHP-фреймворк, следующий архитектурному паттерну MVC (Model-View-Controller). Он предоставляет выразительный синтаксис и богатый набор инструментов.

**Роль в проекте:**
- **Упрощает создание веб-интерфейса.** Маршрутизация, контроллеры, шаблоны — всё структурировано и удобно.
- **Обеспечивает безопасность.** Защита от CSRF, XSS, SQL-инъекций (хотя SQL в проекте не используется напрямую).
- **Интегрируется с внешними сервисами.** Через HTTP-клиент Guzzle.
- **Облегчает валидацию данных.** Встроенные правила валидации форм.

**Ключевые компоненты Laravel, используемые в проекте:**
- **Маршрутизация (routes/web.php).** Определяет URL-адреса приложения.
- **Контроллеры (app/Http/Controllers).** Содержат логику обработки запросов и взаимодействия с API.
- **Blade-шаблоны (resources/views).** Обеспечивают разделение логики отображения и PHP-кода.
- **Валидация запросов.** Правила валидации в контроллерах.
- **Middleware.** Например, для проверки сессии (хотя в проекте аутентификация на стороне API).
- **Конфигурация (config/).** Удобное управление настройками (например, базовый URL API).

**Почему выбран:** Laravel предоставляет всё необходимое для быстрого создания качественного веб-интерфейса и имеет отличную документацию. Он идеально подходит для проектов, где основная логика вынесена в отдельное API.

## 3. HTTP-клиент Guzzle
Guzzle — мощная PHP-библиотека для отправки HTTP-запросов. В Laravel она включена по умолчанию.

**Назначение в проекте:**
- Выступает единственным каналом связи между фронтендом и бэкендом.
- Отправляет GET, POST, PUT, DELETE запросы к C# API.
- Обрабатывает ответы (JSON) и превращает их в массивы PHP.
- Позволяет настраивать таймауты, заголовки, обрабатывать ошибки.

**Реализация:** Все обращения к API инкапсулированы в сервис `App\Services\ApiService`. Это делает код контроллеров чистым и облегчает возможную замену HTTP-клиента.

## 4. Шаблонизатор Blade
Blade — простой, но мощный шаблонизатор, встроенный в Laravel.

**Возможности, использованные в проекте:**
- **Наследование макетов.** Единый макет `layouts/app.blade.php` содержит общую структуру (header, footer, подключение стилей), а страницы его расширяют.
- **Секции (`@section`, `@yield`, `@show`).** Позволяют подставлять контент в разные части макета.
- **Управляющие структуры.** `@if`, `@foreach`, `@isset` для отображения данных.
- **Экранирование вывода.** Автоматическая защита от XSS-атак.
- **Компоненты и слоты.** (Могут быть использованы для более сложной композиции).

**Преимущества:** Blade-шаблоны легко читать и писать, они компилируются в обычный PHP-код, поэтому работают быстро.

## 5. Bootstrap 5
Bootstrap — самый популярный CSS-фреймворк для создания адаптивных и современных веб-интерфейсов.

**Использование в проекте:**
- **Сетка (grid).** Для построения отзывчивых макетов (ряды, колонки).
- **Компоненты.** Кнопки, формы, таблицы, навигационная панель, карточки, модальные окна.
- **Утилиты.** Классы для быстрого управления отступами, цветами, выравниванием.
- **Адаптивность.** Интерфейс корректно отображается на мобильных устройствах.

**Обоснование:** Bootstrap ускоряет вёрстку, обеспечивает единообразный вид на всех страницах и не требует глубоких знаний CSS. Это идеальный выбор для учебного проекта.

## 6. JavaScript (vanilla JS)
JavaScript используется для добавления интерактивности на стороне клиента. В проекте он решает следующие задачи:
- **Подтверждение удаления.** Перед отправкой формы удаления появляется диалоговое окно с вопросом.
- **Динамическая фильтрация (опционально).** Можно реализовать поиск без перезагрузки страницы с помощью Fetch API.
- **Улучшение пользовательского опыта.** Например, автофокус на поле ввода.

**Почему не выбран отдельный фреймворк (React/Vue):** Текущая функциональность не требует сложной клиентской логики. Использование чистого JavaScript (vanilla JS) достаточно и не усложняет проект. При необходимости Laravel легко интегрируется с Vue или React, но в рамках курсовой работы это избыточно.

## 7. Дополнительные инструменты
- **Composer** — менеджер зависимостей PHP. Используется для установки Laravel, Guzzle и других пакетов.
- **Artisan** — командная строка Laravel. Позволяет генерировать контроллеры, создавать миграции (хотя миграции не используются, так как данные хранятся в MySQL через API), чистить кэш и многое другое.

## Заключение
Фронтенд на Laravel обеспечивает удобный и понятный интерфейс для работы с системой, использует проверенные технологии и легко масштабируется. Интеграция с C# API через Guzzle позволяет чётко разделить серверную логику и представление, что соответствует современным подходам к разработке. Выбранный стек полностью соответствует задачам курсового проекта и позволяет успешно реализовать клиентскую часть информационной системы «Студент-Менеджер».

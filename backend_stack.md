# Обоснование выбора технологического стека для бэкенда (C#)

**Разработчик:** Соловьёв Глеб

## 1. Язык программирования C# (версия 12)
C# — современный объектно-ориентированный язык с строгой типизацией, разработанный компанией Microsoft. Входит в экосистему .NET и является одним из самых популярных языков для создания корпоративных приложений.

**Причины выбора для проекта:**
- **Надёжность и производительность.** Благодаря JIT-компиляции и оптимизациям CLR приложения на C# демонстрируют высокую скорость работы, что важно для обработки запросов от многих пользователей.
- **Богатая стандартная библиотека.** Встроенные средства для работы с сетью, файлами, шифрованием, сериализацией ускоряют разработку.
- **Асинхронное программирование.** Ключевые слова `async`/`await` позволяют эффективно обрабатывать множество одновременных запросов без блокировок.
- **Строгая типизация.** Многие ошибки выявляются на этапе компиляции, что повышает стабильность системы.
- **Кроссплатформенность.** .NET Core (ныне .NET 5+) работает на Windows, Linux и macOS, что даёт свободу выбора серверной ОС.
- **Большое сообщество и поддержка Microsoft.** Обилие библиотек, документации и примеров упрощает решение типовых задач.

## 2. Платформа .NET 8
.NET 8 — это кроссплатформенная среда выполнения с долгосрочной поддержкой (LTS). Она включает в себя библиотеки базовых классов, компиляторы и инструменты для сборки приложений.

**Роль в проекте:**
- Служит основой для запуска веб-сервера и выполнения бизнес-логики.
- Обеспечивает интеграцию с операционной системой, управление памятью, безопасность.
- Предоставляет унифицированную модель для консольных приложений, веб-API и фоновых служб.

**Преимущества:**
- Высокая производительность (TechEmpower benchmarks).
- Встроенная поддержка контейнеризации (Docker).
- Единая экосистема для всех компонентов (логирование, конфигурация, DI).

## 3. Фреймворк ASP.NET Core Web API
ASP.NET Core — это высокопроизводительный фреймворк для создания веб-приложений и API. В проекте используется его специализация **Web API** для построения RESTful сервисов.

**Ключевые возможности:**
- **Маршрутизация на основе атрибутов.** Удобное определение эндпоинтов.
- **Встроенный контейнер внедрения зависимостей (DI).** Облегчает тестирование и соблюдение принципов SOLID.
- **Middleware pipeline.** Гибкая обработка HTTP-запросов (аутентификация, логирование, CORS).
- **Автоматическое согласование контента.** Возврат данных в JSON (или XML) по запросу.
- **Встроенная поддержка OpenAPI (Swagger).** Автоматическая генерация документации.

**Почему выбран:** Позволяет быстро и с минимальными усилиями создать качественное API, которое будет легко поддерживать и расширять. ASP.NET Core входит в топ самых быстрых веб-фреймворков, что критично для производительности ИС.

## 4. Entity Framework Core (ORM) версии 8.0
Entity Framework Core (EF Core) — объектно-реляционный映射 (ORM) для .NET, позволяющий работать с базами данных через объекты C#.

**Функции в проекте:**
- **Автоматизация создания и обновления схемы БД.** Миграции EF Core синхронизируют модель данных с физической базой.
- **Выполнение запросов через LINQ.** Вместо написания SQL-кода используются строго типизированные запросы.
- **Отслеживание изменений.** EF Core автоматически формирует команды UPDATE/INSERT/DELETE при сохранении изменений.
- **Поддержка отношений.** Легко настраиваются связи между таблицами (один-ко-многим, многие-ко-многим).
- **Поддержка провайдеров.** Через провайдеры EF Core может работать с различными СУБД (в проекте используется Pomelo для MySQL).

**Обоснование:** EF Core сокращает время разработки, уменьшает количество ошибок, связанных с ручным написанием SQL, и облегчает рефакторинг модели данных. При этом он достаточно производителен для большинства сценариев, особенно при правильном использовании (асинхронные запросы, отключение отслеживания для чтения).

## 5. СУБД MySQL 8.0
MySQL — одна из самых популярных реляционных баз данных с открытым исходным кодом.

**Причины выбора:**
- **Бесплатность и открытость.** Идеально для учебных проектов и некоммерческого использования.
- **Высокая производительность и надёжность.** MySQL успешно работает в крупных проектах (Facebook, YouTube).
- **Поддержка стандартного SQL и расширенных функций** (транзакции, хранимые процедуры, представления).
- **Простота администрирования.** Инструменты вроде phpMyAdmin, MySQL Workbench облегчают управление.
- **Хорошая совместимость с .NET через провайдер Pomelo.EntityFrameworkCore.MySql.** Провайдер поддерживает все возможности EF Core и регулярно обновляется.

**Роль в проекте:** Хранит все данные системы: информацию о студентах, группах, родителях, успеваемости, посещаемости, пользователях и сообщениях.

## 6. Провайдер Pomelo.EntityFrameworkCore.MySql
Этот пакет является мостом между EF Core и MySQL. Он транслирует LINQ-запросы в SQL, понятный MySQL, и обрабатывает специфические для MySQL типы данных и функции.

**Почему выбран:** Это самый популярный и поддерживаемый провайдер MySQL для EF Core. Обеспечивает полную совместимость с последними версиями как EF Core, так и MySQL.

## 7. Аутентификация и авторизация (JWT)
JSON Web Token (JWT) — открытый стандарт для создания токенов доступа, основанный на JSON. В проекте используется для защиты API.

**Компоненты:**
- **Microsoft.AspNetCore.Authentication.JwtBearer** — middleware для проверки JWT-токенов.
- **JWT-токены** содержат утверждения (claims) о пользователе (ID, роль, отделение) и подписываются секретным ключом.

**Преимущества подхода:**
- **Stateless (без сохранения состояния).** Серверу не нужно хранить сессии, что упрощает масштабирование.
- **Поддержка разных клиентов.** Токен может использоваться веб-приложением, мобильным приложением или даже внешними сервисами.
- **Встраивание ролей и прав.** Роль пользователя хранится в токене, что позволяет легко проверять доступ в контроллерах через атрибут `[Authorize(Roles = "admin")]`.

**Реализация в проекте:** Контроллер `AuthController` обрабатывает логин и выдаёт токен. Для защищённых эндпоинтов клиент должен передавать токен в заголовке `Authorization`.

## 8. Swagger (OpenAPI)
Swagger (реализованный через пакет Swashbuckle.AspNetCore) автоматически генерирует документацию API в формате OpenAPI и предоставляет интерактивный интерфейс для тестирования.

**Назначение:**
- Упрощает отладку и тестирование API в процессе разработки.
- Служит документацией для фронтенд-разработчиков, позволяя быстро понять, какие эндпоинты доступны и какие данные они ожидают.
- Повышает качество кода, так как стимулирует использовать XML-комментарии и аннотации.

## 9. CORS (Cross-Origin Resource Sharing)
CORS — механизм, позволяющий веб-страницам запрашивать ресурсы с другого домена. В проекте настроена политика `AllowAll`, разрешающая запросы с любых источников. Это упрощает разработку, когда фронтенд и бэкенд запущены на разных портах/доменах. В производственной среде политика может быть ограничена конкретными доменами.

Выбранный стек для бэкенда обеспечивает надёжное, производительное и масштабируемое API с чёткой архитектурой. Использование современных инструментов (EF Core, JWT, Swagger) позволяет сократить время разработки и получить качественный результат, полностью соответствующий задачам курсового проекта.
